### Purpose of repository

Code used to analyze the ATAC component of the 10X Multiome in Li et al. 2026.

Versions:
- Archr 1.0.2 [https://github.com/GreenleafLab/ArchR](url) - used for dimensionality reduction/creation of tile/peak matrices. chromVar, footprinting, and differential peak calling was all done in ArchR
- Scenic+ 0.12.1 [https://scenicplus.readthedocs.io/en/latest/](url) - used to call joint RNA/ATAC inferred gene regulatory networks
