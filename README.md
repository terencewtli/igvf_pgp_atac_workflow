### Purpose of repository

Code used to analyze the ATAC component of the 10X Multiome in our preprint.

### Citation

Li TW\*, Langerman J\*, Liu C\*, Sun Y\*, et al. Epigenomic heterogeneity and spatial organization during human reprogramming. *bioRxiv* (2026). [https://doi.org/10.64898/2026.10.15.757424](https://www.biorxiv.org/content/10.64898/2026.10.15.757424v1)

\*These authors contributed equally.

[https://ucla-igvf-pgp-reprogramming.pages.dev/](https://ucla-igvf-pgp-reprogramming.pages.dev/)

### Versions
- Archr 1.0.2 [https://github.com/GreenleafLab/ArchR](https://github.com/GreenleafLab/ArchR) - used for dimensionality reduction/creation of tile/peak matrices. chromVar, footprinting, and differential peak calling was all done in ArchR
- Scenic+ 0.12.1 [https://scenicplus.readthedocs.io/en/latest/](https://scenicplus.readthedocs.io/en/latest/) - used to call joint RNA/ATAC inferred gene regulatory networks
